# 💇 Salon Booking & Management System

A frontend practice project for a **Salon Booking & Management System**, created to improve my skills in HTML, CSS, and JavaScript.

## 👩‍💻 About the Project

Hi! I'm **Shrutika Ambure**.

I created this project as a **frontend practice project** to learn and experiment with building an interactive web application.

The project includes separate interfaces for customers and administrators, along with various salon booking and management features.

## ✨ Features

### 👤 Customer Side

* Customer registration and login
* Browse salon services
* Select date and time
* Select stylist
* Select available seat
* Book an appointment
* Payment interface
* View booking history
* Cancel bookings
* Queue/token information

### 🛠️ Admin Side

* Admin dashboard
* View customers
* Manage services
* Manage staff/stylists
* View bookings
* View payment information
* View reports and salon statistics

## 🧑‍💻 Technologies Used

* HTML5
* CSS3
* JavaScript
* LocalStorage
* Responsive Web Design

## 🎯 Purpose

This project was created **only for practice and learning purposes**.

Through this project, I practiced:

* Building responsive user interfaces
* DOM manipulation
* JavaScript logic

* Dynamic content rendering
* Managing data with LocalStorage
* Creating dashboards
* Designing booking workflows
* Improving UI/UX

## 📱 Project Type

**Frontend Project**

This project currently works on the frontend and uses browser storage for demonstration purposes. It is not intended to be a production-ready salon management system.
