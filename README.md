💇 Salon Booking & Management System

A frontend Salon Booking & Management System developed using HTML, CSS, and JavaScript. The project provides interactive customer and admin interfaces with multilingual support in English, Hindi, and Marathi.

👩‍💻 About the Project

Hi! I'm Shrutika Ambure.

I created this project to practice frontend development and build an interactive salon booking application.

The system includes separate interfaces for customers and administrators, along with salon booking, payment, queue, and management features.

✨ Features

👤 Customer Side

- Customer registration and login
- Browse salon services
- Select date and time
- Select stylist
- Select available seat
- Book appointments
- Payment interface
- View booking history
- Cancel bookings
- Queue/token information
- Multilingual support: English, Hindi & Marathi

🛠️ Admin Side

- Admin dashboard
- View customers
- Manage services
- Manage staff/stylists
- View bookings
- View payment information
- View reports and salon statistics
- Multilingual support: English, Hindi & Marathi

🌐 Language Support

The application supports three languages:

- 🇬🇧 English
- 🇮🇳 Hindi
- 🇮🇳 Marathi

Users can switch between languages within the application interface.
